Lakukan audit dan refactor seluruh sistem setup bot.

JANGAN menambah fitur baru yang tidak ada di project. Fokus hanya memperbaiki fitur yang sudah ada.

========================
1. SATUKAN SEMUA SETUP
========================

Hapus seluruh command setup yang terpisah.

Semua konfigurasi dipindahkan ke SATU command saja:

/setup

Jangan ada lagi:
- /setupboombox
- /setupwelcome
- /setupgoodbye
- /setuplogs
- command popup lama
- command setup lain

Semuanya dipindahkan ke wizard /setup.

========================
2. GANTI BUTTON MENJADI DROPDOWN
========================

Panel setup saat ini masih memakai banyak button.

Ubah menjadi StringSelectMenu (Dropdown).

Contoh:

📂 BoomBox
👋 Welcome
👋 Goodbye
🎭 Take Role
📢 Logs
🛠 Moderasi
🎫 Ticket
🎁 Giveaway
⚙ Pengaturan
dll...

Saat memilih dropdown baru muncul menu konfigurasi fitur tersebut.

Jangan memakai banyak button lagi.

========================
3. RAPIIKAN UI
========================

Hilangkan tulisan yang tidak penting seperti:

Powered by ...
Queue...
Mohon tunggu...
Estimasi...
Link berhasil diterima...
Pesan ini hanya dapat dilihat oleh kamu.

Kalau tidak benar-benar diperlukan jangan ditampilkan.

Embed dibuat bersih dan minimalis.

========================
4. BOOMBOX
========================

BoomBox jangan mengirim banyak pesan.

Saat user kirim link:

langsung proses

kalau berhasil cukup edit embed

jangan spam reply

jangan spam followup

jangan spam ephemeral

Gunakan satu embed saja.

========================
5. SETUP BOOMBOX
========================

Semua pengaturan BoomBox dipindah ke wizard.

Contoh:

Dropdown

BoomBox

↓

submenu:

Channel

Logs

Maintenance

Monitor

Durasi

Status Platform

Reset

Tidak memakai button banyak seperti sekarang.

========================
6. RESET
========================

Semua kategori setup wajib memiliki tombol:

Reset Konfigurasi

Saat dipilih:

hapus seluruh config fitur tersebut

bersihkan database config

kembali ke default

========================
7. COMMAND LAMA
========================

Kalau sebuah command sudah dipindahkan ke wizard setup

hapus command lama dari bot.

Tidak boleh ada duplicate.

========================
8. BERSIHKAN UI
========================

Hilangkan panel-panel lama yang sudah tidak dipakai.

Hilangkan popup command lama.

Hilangkan menu setup lama.

Sisakan hanya:

/setup

========================
9. AUDIT
========================

Cari semua command konfigurasi di project.

Pastikan seluruhnya sudah masuk ke wizard /setup.

Kalau ada yang belum masuk, pindahkan.

========================
10. JANGAN MENAMBAH FITUR BARU
========================

Jangan membuat fitur baru.

Jangan membuat command baru.

Jangan mengubah fungsi fitur.

Hanya:
- rapikan
- satukan
- pindahkan
- perbaiki bug
- bersihkan UI
- hapus command setup lama
- gunakan dropdown
- gunakan submenu
